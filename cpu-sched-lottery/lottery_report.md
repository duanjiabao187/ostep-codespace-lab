# 彩票调度实验报告

## 一、实验原理
彩票调度（Lottery Scheduling）是一种基于概率的CPU调度算法：
- 为每个进程分配一定数量的"彩票"
- 每次调度随机抽取一张彩票，持有者获得CPU使用权
- 票数占比 ≈ 获得CPU时间的占比

### 实验2：票数 3:1 —— 优先级调度
**命令**
```bash
python3 lottery.py -l 10:3,10:1 -m 10 -s 0 -c
```

**结果**
- Job 0：运行 0 个时间片
- Job 1：运行 4 个时间片
- 总时长：20 个时间片

**分析**
固定随机种子下单次结果有偏差；增加总运行步数后，占比会趋近票数比例 3:1。

---
### 实验3：票数 1:2:3 —— 多进程比例分配
**命令**
```bash
python3 lottery.py -l 10:1,10:2,10:3 -m 12 -s 0 -c
```

**结果**
- Job 0：运行 1 个时间片
- Job 1：运行 1 个时间片
- Job 2：运行 0 个时间片
- 总时长：30 个时间片

**分析**
进程数越多、总时间越短时，随机性越明显；运行时间越长，实际占比越接近票数占比。

## 三、结论
1. 彩票调度是**概率性**算法，单次结果可能偏离预期
2. 满足**大数定律**：运行时间越长，分配越接近票数比例
3. 优点：实现简单、支持动态调整优先级、公平性好
4. 缺点：短时间内分配可能不均
